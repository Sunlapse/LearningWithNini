For Parents & Teachers

Learn With Nini is a family-created math practice site built around a daily 20-minute challenge and short skill games. Students first choose Grade 2, 3, 4, or 5, then choose Standard, Review, or Challenge mode. Review and Challenge both stay within the selected grade rather than mixing grade levels. At the end of each Daily Challenge, the site looks at questions that were missed, skipped, or needed another try and recommends matching games for targeted practice.

No student accountsNo login or student email is required to play.
Nickname-only leaderboardStudents should use a fun nickname, not a real name or email address.
Practice, not gradingScores are for motivation and progress, not formal assessment.

How to use Learn With Nini

🏠 At home

  1. Start with the Daily 20-Minute Challenge. Choose the child’s grade, then Standard for balanced practice, Review for foundational/core skills, or Challenge for harder stretch and multi-step work within that same grade.
  2. At the end, review the recommended games based on questions that were missed, skipped, or needed another try.
  3. Choose the top recommendation for 5–10 more minutes of focused practice.
  4. Return the next day and repeat the cycle: mixed practice → identify gaps → targeted game practice.
  5. Use the leaderboard as optional motivation, not pressure.

🏫 In class

  • Use the Daily Challenge as a mixed-skills check-in, then use the end-of-challenge recommendations to choose targeted follow-up practice.
  • Use a skill game for a math center or early-finisher station.
  • Project a game for whole-class warm-up or guided practice.
  • Assign a topic rather than a score target so students can work at their own pace.
  • Ask students to use non-identifying nicknames if they use the leaderboard.

Suggested routine

20–30 minutes total: Daily Challenge → review the recommended practice games → choose the top matching skill game → quick review of mistakes. The recommendation system is meant to guide practice, not grade a child. A child does not need to finish every game or chase leaderboard scores.
